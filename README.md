# Christopher Ryu

Software engineer at **AWS Annapurna Labs**, working on disaggregated AI inference and GPU communication. I contribute to [NIXL](https://github.com/ai-dynamo/nixl), [libfabric](https://github.com/ofiwg/libfabric), and [aws-ofi-nccl](https://github.com/aws/aws-ofi-nccl), with a focus on libfabric integration for NIXL and NCCL.

Selected NIXL pull requests: [NIC selection by PCIe depth](https://github.com/ai-dynamo/nixl/pull/2640), [host-route NIC assignment](https://github.com/ai-dynamo/nixl/pull/2639), and [GDRCopy on EFA rails](https://github.com/ai-dynamo/nixl/pull/2629).

Previously at **Amazon Fire TV**, where I led Vega OS UI delivery and developed [Carousel](https://www.developer.amazon.com/docs/vega-api/0.21/carousel), a C++-backed React Native scrolling component. My work also included Rust device software and Java and Kotlin backend services.

Research code: [gem5 cache-control experiments](https://github.com/chrislryu/ccsca-gem5/tree/ccsca-stable) and an [angr cache-memory mixin](https://github.com/chrislryu/angr/tree/cache-mixin-development).

Coauthor of [Simulating Our Way to Safer Software: A Tale of Integrating Microarchitecture Simulation and Leakage Estimation Modeling](https://doi.org/10.1109/LCA.2023.3303913), published in *IEEE Computer Architecture Letters* (2023).
